
# HealthyMe v94 Supabase Storage Setup

## Buckets

Create two buckets in Supabase Storage:

1. `healthyme-public-assets`
   - Public bucket: Yes
   - Purpose: generic exercise images, generic recipe placeholders, public wellness visuals

2. `healthyme-private-content-assets`
   - Public bucket: No
   - Purpose: nutritionist-created recipe images, premium assets, restricted content

## Environment variables

Recommended:

```env
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
HEALTHYME_PUBLIC_ASSETS_BUCKET=healthyme-public-assets
HEALTHYME_PRIVATE_ASSETS_BUCKET=healthyme-private-content-assets
HEALTHYME_SIGNED_URL_TTL_SECONDS=21600
```

If service role is not available in Streamlit Cloud, use existing Supabase key variables used by the app, but uploads may fail depending on Storage policies.

## Storage policies

Public bucket:
- Allow public read.
- Allow authenticated/admin upload or service-role upload.

Private bucket:
- No public read.
- Allow service-role upload.
- Member display uses signed URLs generated by the app.

## Admin flow

Recipe / Exercise manager:
1. Add title and other content fields.
2. Choose uploaded image visibility.
3. Upload image to Supabase.
4. Save recipe/exercise record.
5. Member side resolves image automatically.
