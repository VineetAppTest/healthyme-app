# H9A.10E Journey and Weekly Plan Separation

Clarifies the member-facing naming and structure.

## Product structure

- Today's Journey is the member's one-day actionable slice.
- My Weekly Plan is the full seven-day recommendation.
- Today's Journey is pulled from My Weekly Plan, not maintained separately.

## Naming

Use member-facing labels:

- Today's Journey
- My Weekly Plan

Avoid using the technical label Member Plan in the visible member UI except for the route/file name.

## Route behavior

- Today's Journey route shows only today's calculated day.
- Weekly Plan route shows the complete seven-day plan.
- Weekly Plan remains split into Meals, Supplements, Exercises and Nutrition Guidance tabs.

## Acceptance

1. Member Home or member navigation exposes two separate options where applicable.
2. Today's Journey does not display the full weekly content by default.
3. My Weekly Plan clearly communicates that it is the overall seven-day plan.
4. Both views use the same active published profile as source of truth.
